# Homebrew tap for Proscenium

[Proscenium](https://proscenium.ink) is a Mac app for writing plays.

```sh
brew install --cask proscenium-app/tap/proscenium
```

The cask in `Casks/proscenium.rb` is updated automatically each time a release
is published on [proscenium-app/proscenium](https://github.com/proscenium-app/proscenium/releases).
Proscenium updates itself once installed; `brew upgrade` is not needed.
